# Food_Life
This mobile lets an user enter the food and its details such as its expiry date, name of the food, category of food, its amount, unit, and note and will give the user a notification before its expiry date. The goal of this app is to reduce the food waste by keeping the track of the food life in the fridge or pantry.

# Features
- Add food items
- Categorize food
- Set expiration date
- Save the details of food item(amount, note and unit of the amount)
- Get a notification before its expiration date
- Delete food item
- Edit food item
- View the food item(s)
